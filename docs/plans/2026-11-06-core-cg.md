# Core CG implementation plan

**Goal:** Add matrix-free conjugate gradients for real symmetric and complex
Hermitian positive-definite systems in `tensor4all-core`.

**Architecture:** A focused `src/krylov/cg.rs` module, re-exported from
`krylov`, uses `TensorVectorSpace` and existing `AnyScalar` arithmetic.
KrylovKit's CG implementation at revision
`d51fa25adfa4cda5530d8e3d42eedfb288cca447` is the reference. CG is independent
of TreeTN sweep integration and tensor-network compression.

**Constraints:** No new dependencies or changes to existing test tolerances.
Commits are made by the maintainer. Work from synchronized `origin/main` on
`feat-core-cg`. Execute directly in this checkout.

## Deliverable and checks

- [x] Add failing tests in `crates/tensor4all-core/src/krylov/tests/cg.rs`:
  known real/complex HPD solutions, generic vectors, zero RHS, exact guesses,
  iteration limits, absolute/relative tolerance, invalid options, incompatible
  vectors, callback errors, nonfinite arithmetic, nonpositive curvature, and
  observable non-Hermitian curvature.
- [x] Add `cg(apply_a, b, x0, &CgOptions) -> Result<CgResult<T>, KrylovError>`.
  Options are `max_iter`, `rtol`, `atol`, and `hermitian_tol`; convergence is
  `||b-Ax|| <= max(atol, rtol*||b||)`. Zero iterations are allowed. Return the
  true absolute residual norm, completed iterations, and convergence flag.
- [x] Recompute the true residual before convergence and on exhaustion;
  restart from it if estimated convergence was premature, within the same
  iteration budget. Keep recurrence coefficients in `AnyScalar` space.
- [x] Preserve upstream license/attribution and document the public contract
  and provenance. Check README and bundled skill consistency.
- [x] Run focused tests, changed-crate tests, doctests, rustdoc, Clippy,
  formatting, public-error documentation and deterministic rules checks.
  Review the integrated diff before handing it over for the maintainer's commit.

## Review focus

- Complex inner products conjugate their first operand.
- Zero RHS must not bypass shape checks or discard a nonzero initial guess.
- Numerical breakdown must not return a NaN solution as converged.
- Recursive residual drift must not produce false convergence.
- Hermitian checks inspect visited directions and do not certify the full
  matrix-free operator; the caller supplies the HPD precondition.
