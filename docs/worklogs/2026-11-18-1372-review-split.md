# Opt-in TreeTCI convergence confirmation (#1372)

## Decisions

[Hiroshi's final baseline decision](https://github.com/tensor4all/tensor4all-rs/pull/1372#issuecomment-7011804494)
pins the default to main `35174fdd`, including ordinary global-search residuals.
The earlier per-sweep-history design at `2b284c62` is superseded. Historical
`501ebb4a` defines a cost reference only. Julia-compatible stopping, local-error
allocation and #1371's default stall remain separate work in #1405.

Confirmation is explicitly opt-in and runs only when ordinary convergence would
return. The [stopping contract](../design/treetci-termination.md) owns its failure,
retry and floor semantics. Disabled history uses a concrete zero-sized owner,
selected once at the run boundary, so oracle loops have no runtime history mode.
Current retained-pair metadata and the cached residual readout are shared rather
than duplicated between validation and search. Complementary-subtree restarts
rotate retained anchors within the existing restart budget: using only the last
anchor missed the complex frozen-plane counterexample.

The normal regressions keep seed 4 for each scalar, which reproduces false
convergence on main, and a three-site fixed-seed eviction case. The 32-site
resource run and 16-seed survey are ignored heavy tests, following the
[maintainer's runtime request](https://github.com/tensor4all/tensor4all-rs/pull/1372#issuecomment-7008882660).
Their existing numerical tolerances are preserved. Default partitioned golden
records are restored exactly from main; opt-in behavior does not re-record them.

## Verification conclusions and constraints

The frozen real/complex seed-4 cases both fail one confirmation, receive a pivot,
and converge after three fresh sweeps and a second successful confirmation.
Their dense errors meet the unchanged 1e-10 tolerance. The independent main
reference reports convergence with approximately 6.33e-10 dense error on both.
The heavy survey checks every seed 1–16 with the same accuracy assertion; both
32-site budgets reach exactly 30 sweeps / MaxIterations, with history eviction.

Focused controls cover default-main bit equality (including 203 oracle points),
failed-check injection and the fresh window, final failure without injection,
repeated-snapshot floors, changing pivots at fixed rank, cap/iteration/zero-tolerance
paths without confirmation, malformed callback results, memoization, retained
pair orientation and bounded history ownership. Removed per-sweep/final/cap
validation tests exercised superseded behavior; shared geometry, residual readout,
callback validation and protected-witness coverage remain in their owning suites.
No assertion tolerance is relaxed. Hosted coverage and provider matrices remain
required, especially macOS pivot trajectories.

The [comparison protocol](../experiments/2026-11-19-confirmation/README.md)
separates current-main parity from historical cost and includes replay in the
measured call. Earlier 7.4–8.4x oracle observations describe the superseded design;
they are not new-head evidence. The preserved local PR B prototype is unmeasured
and must be rebased onto the new baseline before its separate campaign.
