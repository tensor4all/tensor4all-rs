# Retained-pivot validation and PR #1372 review split

## Decisions

[Hiroshi's scope decision](https://github.com/tensor4all/tensor4all-rs/pull/1372#issuecomment-6971978530)
separates retained-pivot validation/seeding/verdicts (PR A, #1352) from the
local-truncation and recovery experiment (draft PR B, #1371). PR A keeps the
local LU threshold unchanged. Its [stopping and bounded-history contract](../design/treetci-termination.md)
protects the largest observed residual witness and checks current retained
pivot pairs independently of the historical budget.

Equal maximum ranks do not establish a stationary approximation. An early
uncapped floor requires unchanged swept pivot sets; otherwise an unresolved run
may reach its iteration limit with an honest recorded error. Resource pressure
limits historical coverage rather than forcing a termination.

[Hiroshi's compatibility clarification](https://github.com/tensor4all/tensor4all-rs/issues/1371#issuecomment-6973070577)
accepts an opt-in Julia-compatible stop for PR B. Defaults keep the recorded
sampled maximum and refuse convergence above tolerance. API spelling waits for
the post-seeding cost comparison, including the 60-site slow-decay comb and the
bounded-recovery noise test. This does not expand PR A.

## Verification conclusions and constraints

The old hosted failures are deterministic: rerunning `5d40fd03` repeats the
Linux merge failure and both macOS failures. [Hiroshi independently reproduces
the merge failure](https://github.com/tensor4all/tensor4all-rs/pull/1372#issuecomment-6973145117).
An isolated original-LU/no-recovery ablation changes the chirp fixture from
21 leaves with five valid rank-two merges to 16 leaves with no merges, while
keeping the merge cap at three. Both approximations meet the original L2
allowance. This identifies the numerical experiment as sufficient to change
that fixture's no-merge assumption. PR A restores the original threshold and
passes the existing merge assertions; it does not change that fixture or its
accuracy threshold. An opt-in numerical experiment can legitimately change
the partition and must validate its own merge behavior separately.

The original [18-run experiment and hashes](https://github.com/tensor4all/tensor4all-rs/blob/5d40fd03b60d17a325af3ff0d8bf092b1e3de328/docs/worklogs/artifacts/2026-11-18-issue1371/README.md)
remain pinned evidence for `5d40fd03`, preserved for PR B. Its reproducer,
artifacts and Gaussian accuracy regression belong to that experiment. They are
not accuracy or performance claims about PR A. PR A retains the unchanged dense
#1352 regression thresholds and independent resource/verdict controls.

Original LU at tolerance 1e-6, seed 2 retains the published unsampled Gaussian
miss: recorded 9.93e-7 versus dense 1.018e-6. Sampled convergence is not a dense
error bound; PR A does not solve that #1371 numerical-policy limitation by
relaxing a tolerance or changing the local threshold.

Local validation passes TreeTCI's unit and integration suites, the unchanged
#1352 dense comparisons, optimized numerical regressions, the downstream
partitioned unit/integration suites, affected doctests and Clippy. No numerical
assertion tolerance is relaxed. The 32-site seed-two runs reach the requested
30 sweeps at both 32 MiB and 64 KiB, with eviction and an above-tolerance
recorded error, rather than a history-budget stop or false convergence. Their
remaining numerical stall belongs to PR B.

The two TreeTCI golden records keep their function evaluations, splits,
terminations, bond dimensions and node data. Cache hits become 31663 and 51349,
and a few error estimates change within 3.4e-16; only those intentional fields
are re-recorded. Dense-engine records and every comparison tolerance remain
unchanged. Hosted verification is required on the synchronized PR A head,
especially macOS because pivot trajectories differ across providers.
