# TreeTCI rank-slack numerical verification

The opt-in rank rule from [#1264](https://github.com/tensor4all/tensor4all-rs/issues/1264)
was checked against the issue's three-softened-Coulomb-bump target. All 48
cases below returned `Converged`. The complete per-seed diagnostics are in
[results.csv](results.csv), including rank, recorded-error and global-pivot
histories. No timing or speedup claim is made.

| Family | Rank slack | Seeds | Iterations | Held-out relative L2 error | Held-out relative max error |
| --- | --- | --- | --- | --- | --- |
| chain | 0 | 20 | 6–8 | 1.72001e-06–2.14225e-06 | 1.29052e-06–2.07999e-06 |
| chain | 0.03 | 20 | 6 | 1.72001e-06–2.38532e-06 | 1.29052e-06–2.08618e-06 |
| comb | 0 | 4 | 5–6 | 2.12185e-08–2.74958e-08 | 1.48163e-08–2.23707e-08 |
| comb | 0.03 | 4 | 5 | 2.12185e-08–2.76967e-08 | 1.48163e-08–2.35973e-08 |

The chain uses 24 binary sites (8 bits per axis), tolerance `1e-6`, and seeds
1–20. The comb reuses the provided target with 60 binary sites (20 bits per
axis), tolerance `1e-8`, and seeds 1–4. The latter is an additional topology
check; it does not reproduce the issue's separately mentioned, unspecified
rank-216 comb target or its historical 7–9 iteration claim.

Each seed compares slack `0.0` and `0.03`, with default `ncheck_history = 3`,
`StopRule::PerBond`, `max_iter = 30`, and the all-zero initial pivot. Both
settings use the same 20,000 held-out points per family, generated by ChaCha8
with seed 1264. This held-out stream differs from the issue's xorshift stream,
so its error values need not match the original table. Recorded pivot errors
are sampled diagnostics and do not bound these held-out errors. The controlled
[early-stop regression](../../../crates/tensor4all-treetci/tests/issue1264_rank_slack.rs) separately demonstrates that a
large slack can lose accuracy; these families do not establish a universal
accuracy guarantee for `0.03`.

## Reproduction and provenance

The runnable source is
[rank_slack.rs](../../../crates/tensor4all-treetci/examples/rank_slack.rs).
The numerical executable was built from the standalone #1264 commit
`7418c6830d9cdc4a66b1f31a28856df5affbeb32`, on base `fc8788f2`, using the
release profile and the faer-backed CPU backend. Its TreeTCI numerical source
is unchanged in the combined #1264/#1381 branch. The combined branch was
separately checked after synchronization with `main` `6e91db5c`.

- CPU: AMD Ryzen 9 6900HX, Linux x86_64.
- Thread variables: `RAYON_NUM_THREADS`, `OMP_NUM_THREADS`, `BLAS_NUM_THREADS`,
  `OPENBLAS_NUM_THREADS`, and `MKL_NUM_THREADS` were all `1`.
- Executable SHA-256: `a1894425aabfc59af83d3c94b306aca6a3c901a0757f46e35a04da4fc7873fe7`.
- `Cargo.lock` SHA-256: `f5ebfa0a593fd3e04cf045f25c42a62b7eb4116f35a25b32d858378da556615e`.
- Every build and numerical run used `ai-run build` with an explicit memory cap.
  Seed partitions ran concurrently; these results compare numerical behavior,
  not elapsed time. The first three complete chain pairs were retained from
  an initial serial process; the remaining seeds ran in independent partitions.
  Every family/seed/slack case appears exactly once in the CSV.

```bash
ai-run build --mem 6G -- cargo build --locked --release \
  -p tensor4all-treetci --example rank_slack
export RAYON_NUM_THREADS=1 OMP_NUM_THREADS=1 BLAS_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
ai-run build --mem 1G -- target/release/examples/rank_slack chain 1 20 per-bond
ai-run build --mem 1G -- target/release/examples/rank_slack comb 1 4 per-bond
```

The #1381 core tests passed (1,349 tests, three pre-existing skips), as did
429 core doctests. After the final ownership-only adjustment, the 55 focused
contraction units and 11 prepared-contraction integrations passed again.
On the combined branch after synchronization with `main`, TreeTCI and Quantics
TCI passed all 331 ordinary tests (five pre-existing heavy-test skips), and the
full `scripts/test-mdbook.sh` run passed. Affected crate doctests, strict
Clippy, explicit-only core compilation, API inventory, public error docs,
implicit-engine ratchet, and deterministic repository review also passed.

these fixes. Hosted CI and coverage have not run for these local commits.
